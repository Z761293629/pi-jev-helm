路由评测协议模拟器

这个原型回答一个问题：候选路由能否在质量零退化的硬底线下， 把包含 Prompt Cache、分类和模型调用的平均总费用至少降低 20%？

原型，不是生产实现。双击本文件即可运行；所有状态只存在内存中。

协议草案

双成本基线
候选同时与当前 Helm、始终强模型比较；每条任务轨迹固定后配对运行。
质量硬底线
完整任务 A/B 盲评；候选胜率的 95% Wilson 区间下界必须达到 50%，不能只靠“没有发现退化”。
客观零退化
测试、引用、约束满足等通过率不得低于当前 Helm；新增关键失败直接否决。
分层检查
首次分类错误与 Capability Drift 分开报告；任何一层退化都不能被总体平均掩盖。
节省目标
候选平均总费用必须同时不高于当前 Helm 和始终强模型的 80%；包含 cache read/write、预热和分类。
最终判定
质量硬底线、客观检查、20% 节省和 p95 延迟护栏全部通过才采用。
