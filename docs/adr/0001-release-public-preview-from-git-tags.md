# Release the Public Preview from immutable Git tags

Pi Jev Helm's first external release is an MIT-licensed `v0.1.0` Public Preview distributed as a Pi Git package from immutable GitHub tags rather than npm, even though this deliberately leaves `package.json` marked `private`. Pinned Git installation gives users a reproducible version without prematurely committing to an npm package name or stable `1.0` contract; `0.1.x` patches preserve the configuration schema and command grammar, while breaking changes require a new minor version and migration notes. A tag-triggered GitHub Actions workflow must pass deterministic tests, the supported-Pi compatibility matrix, the credentialed real Jev gate, and a fresh Git installation smoke test before creating a GitHub Pre-release; a failed published tag is never moved and is superseded by a new patch version.
