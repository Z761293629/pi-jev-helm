# Offer unsent Continuation Drafts instead of automatic follow-ups

When Completion Verification confidently returns `continue`, Pi Jev Helm offers one generic, editable Continuation Draft in an empty Pi editor after the Helm Run settles rather than sending a follow-up or starting another Turn. This keeps the judgment immediately actionable while preserving user control over content, timing, model cost, and whether work continues at all; Helm never overwrites existing editor text, and `complete`, `blocked`, `inconclusive`, non-interactive modes, or unavailable editor state produce no draft. The draft remains generic because the accepted direct Completion Disposition is not a faithful explanation of the specific gap, and the rejected V2 auxiliary signals were not accurate enough to generate one.
